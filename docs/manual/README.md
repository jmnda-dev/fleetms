# FleetMS User Manual

Task-oriented help for the people who use FleetMS day to day. The manual is
organised by **who you are** and **what you are trying to do**, not by menu.

The docs live in the repository (`docs/manual/`) so they are versioned with the
product — when a screen changes, its guide changes in the same merge request.

## Who is this for?

| If you… | Start here |
| --- | --- |
| Set up and run the organization (owner, admin, office manager) | **[Admin / Owner](#adminowner)** |
| Manage vehicles, maintenance and the team's day-to-day work | Manager guides *(coming soon)* |
| Drive, inspect and report issues from the road | **[For drivers](#for-drivers)** |

## Admin / Owner

1. **[Getting started](admin/getting-started.md)** — sign in, set up your
   organization, choose your roles, invite your team, and add your first
   vehicle. Start here if FleetMS is brand new to you.
2. **[Managing your fleet](admin/managing-fleet.md)** — the vehicle list and
   record, changing status, assignments, renewals (road tax, insurance,
   fitness certificates) and the drivers roster.
3. **[Day-to-day operations: issues & maintenance](admin/day-to-day-operations.md)**
   — report an issue, turn it into a work order, track the job and its cost, and
   stay ahead with service tasks and reminders.
4. **[Inspections](admin/inspections.md)** — design checklist forms in the
   builder, run inspections, review pass/fail submissions with photos, and set
   up recurring schedules.
5. **[Costs & reports](admin/costs-and-reports.md)** — log fuel and expenses,
   then read the reports: cost of ownership (with cost per km), maintenance
   history, fuel economy and the vehicle roster, all exportable to CSV/PDF.
6. **[Inventory](admin/inventory.md)** — the parts catalogue, tracking stock per
   location (receive, consume, transfer), inventory locations, and how parts feed
   work-order costs.
7. **[People & administration](admin/people-and-administration.md)** — managing
   members, roles & permissions, assigning user roles, tags, contacts and
   organization settings.

*More admin guides (billing, feature flags, the platform admin console) will be
added as sections are written.*

## For drivers

Short, phone-friendly help for people who operate the vehicles — no admin
knowledge needed.

1. **[Getting started](driver/getting-started.md)** — sign in (username or
   email), do a vehicle inspection, report a fault, and log fuel.

## Conventions used in these guides

- **Bold** marks something you click or type on screen (a button, a menu item,
  a field label).
- Screenshots are taken from a live demo organisation ("Kabwe Haulage Ltd").
  Your own data and colours may differ, but the layout is the same.
- FleetMS supports **light and dark mode** and several colour themes — the
  toggles are in the top bar. Screenshots here use the default light theme.

## A note on screenshots

The images in `images/` are captured from the running app. If a screen changes,
re-capture the affected shots when you update the guide so the manual and the
product never drift apart.
